# Documentation

- `XiZou_Thesis.pdf`: Xi Zou's March 2001 University of Minnesota master's thesis, "Simulation and Analysis of Mixed Adaptive Cruise Control / Manual Traffic." It documents the same ACC/manual mixed-traffic simulation family and includes the CTH/VTH comparison described in the 2002 conference paper.

The thesis is included as method/provenance documentation. Administrative student files, applications, proposal drafts, presentations, and `license.dat` from the source folder are intentionally excluded.
